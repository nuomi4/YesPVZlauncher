# YesPVZlauncher
谁不想在Mac上玩自己喜欢的PVZ呢！现在我们几乎做到了完整适配，还有商城系统，游戏库来自网络.

# 介绍
此启动器使用wine来实现启动PVZ，不需要复杂的界面，导入就可以使用。
部分游戏库为网络资源，若商城没有您想要的游戏，可以使用导入。
